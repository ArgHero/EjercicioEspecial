Ejercicio Evaluado

Interfaz para visualizar y gestionar artículos de una tienda en línea, utilizando datos de FakeStoreApi en formato JSON. Se presentan varias tarjetas de productos con imágenes, descripciones breves y opciones de interacción, como ver detalles, editar o consultar el precio. Además, hay un botón para cargar productos y un interruptor para cambiar el tema visual de la página. En la parte inferior, se menciona que el diseño está basado en Bootstrap, permitiendo personalización para adaptarlo a diferentes necesidades.
